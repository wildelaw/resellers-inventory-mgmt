Functional Evaluation Prompt

A reusable, self-contained prompt that drives a coding agent to run the full Playwright E2E evaluation across all six completed builds and write docs/FUNCTIONAL_EVALUATION.md. Source of truth: docs/FUNCTIONAL_EVAL_PROMPT.md.

How to use. Copy the prompt below and paste it into any coding agent (Claude Code, opencode, VS Code Copilot, etc.) with access to this repo. The agent will:

  1. Check out each of the 6 completed build branches into isolated git worktrees.
  2. Boot each build via Docker Compose (or npm run dev + seed as fallback).
  3. Write the canonical 5 Playwright E2E spec files from TEST_STRATEGY.md into each worktree if missing.
  4. Run all 5 flows with 18 regression assertions, 3 retries each.
  5. Record per-flow pass/fail, effort estimates (S/M/L/XL), and per-failure remediation prompts.
  6. Write docs/FUNCTIONAL_EVALUATION.md and update site/assets/data.js, then commit only those two files on main.
