How this site works

This is a zero-build, framework-free static site. All evaluation data lives in site/assets/data.js, sourced from docs/BUILD_EVALUATION.md (static) and docs/FUNCTIONAL_EVALUATION.md (functional, when complete). Pages render via vanilla JavaScript — no Node, no Jekyll, no VitePress.

To run the functional evaluation and populate docs/FUNCTIONAL_EVALUATION.md, use the reusable prompt on the Eval Prompt page. After committing the regenerated FUNCTIONAL_EVALUATION.md and updating site/assets/data.js, the site redeploys automatically via GitHub Actions.
